## 生成后的接入流程

1. 18 张图生成后，统一裁成 3:2，压缩到每张 100KB 以内（tinypng.com）
2. 上传到微信云开发的云存储（小程序后台 → 云开发 → 存储），或任意图床
3. 把 18 个图片链接发给 Claude，会自动替换掉现在的线条插图
4. 以后拍了真人视频，同样只需提供视频号 feedId，对应动作自动升级为视频示范
