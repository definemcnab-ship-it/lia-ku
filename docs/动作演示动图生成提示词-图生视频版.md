## 第 1~18 条：每个动作的生成方法

统一操作：【视频生成 → 图生视频】→ 上传定妆图 → 粘贴对应的"运动提示词" → 时长 5 秒 → 生成。

```

匀速循环，起始姿势与结束姿势相同，无镜头运动，无文字
```

## 验收标准（每条生成后自查，不合格就重新生成）

- ✅ 动作解剖学正确（关节弯曲方向对、幅度合理）
- ✅ 手指/四肢数量正常，无扭曲变形
- ✅ 人物形象与定妆图一致
- ✅ 第 1 秒和第 5 秒姿势接近（循环播放不跳变）
- ✅ 背景干净、无文字水印

不满意的条目把**编号**发给 Claude，会帮你调整提示词重试。
